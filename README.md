# GHGL Design Review

Public, static design-review site for the approved Get Home Get Loan brand concepts and responsive page mocks.

This repository contains only HTML, CSS, and approved logo images. It does not contain the legacy PHP application, databases, credentials, customer data, or WordPress files.

## Review areas

- `logo-gallery.html` compares the approved logo options.
- `mocks/index.html` lists page-level mock sets.
- `mocks/home.html` shows the Home page concept at 1440, 1280, 1024, 768, 576, and 320 pixel review breakpoints.

Mock images are design references only. They are not evidence of functional parity, WCAG conformance, or production completion.
